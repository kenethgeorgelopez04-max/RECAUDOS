# Automatizador de Resumen de Recaudos

Aplicación local de apoyo para Registro y Control Académico de la UNAD.

## Descargar y usar

En la página del repositorio en GitHub, pulse el botón verde **Code** y luego **Download ZIP**. Descomprima el ZIP y abra `Automatizador_Resumen_Recaudos_UNAD_v7.html` con un navegador actualizado. La guía es este archivo `README.md`.

El HTML incorpora las librerías y la plantilla. Procesa PDF con texto y DOCX en el navegador sin conexión ni envío de documentos a servidores.

1. Cargue RAI, Recaudos, Facturas y Convenios.
2. Pulse Analizar y revise la conciliación.
3. Documente los ajustes o discrepancias que requieran revisión.
4. Descargue el XLSX; Elaborado por empieza vacío.

El cruce se realiza sólo por número de factura y conserva el orden No. de Recaudos. Los créditos proceden del RAI. Las tarifas históricas discrepantes requieren revisión, sin modificar créditos para hacer coincidir importes. Mientras haya revisiones pendientes puede generarse un borrador identificado.

Este repositorio puede distribuir únicamente la aplicación y esta guía, sin documentos ni resultados de estudiantes.
